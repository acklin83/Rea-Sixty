Rea-Sixty Companion → Stream Deck migrator

Turn your Bitfocus Companion REAPER buttons into a native Elgato Stream Deck profile that drives REAPER through the Rea-Sixty plugin. Reads the official REAPER (cockos-reaper) module and Rea-Sixty's own actions. Runs entirely in your browser — nothing is uploaded.

Before you start

  1. Install the Rea-Sixty Companion Stream Deck plugin (com.reasixty.companion.sdPlugin) into the Elgato Stream Deck app.
  2. In Companion: Import / Export → Export → Full Configuration (or a single page) to get a .companionconfig file.

Buttons that fire a REAPER command — the module's Custom Action (/action <id>) and the transport actions (Play, Stop, Record…) — migrate cleanly. Track-number, volume/pan-fader and marker actions can't become a single Stream Deck key; they're listed so you can remap them by hand.

4 · Download & import

  1. Double-click the downloaded .streamDeckProfile — the Stream Deck app imports it.
  2. Make sure REAPER is running with the Rea-Sixty extension (its bridge on 127.0.0.1:49900).
  3. The device is left unset in the profile, so on import the app lets you assign it to your Stream Deck — pick the one that matches the layout you chose above.
